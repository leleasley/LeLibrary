How LeLibrary works

  • Reads your enabled debrid downloads and groups episodes into series
  • Fetches TMDB metadata for posters, ratings and detail pages
  • Serves it all as a Stremio / Nuvio addon — Movies, Series and Anime

Your privacy

  • API keys are encoded in the addon URL — sent to the server only when Stremio fetches your library
  • Keys are never stored in a database or logged
  • No tracking, analytics, or third-party requests

Requirements

  • A TorBox and/or Real-Debrid account with downloads
  • A free TMDB API key
  • Poster/Ratings/Stream enhancements are all optional

Edit Catalogues Beta

Choose which catalogues get installed. Importing collections from other addons is coming soon.

These control what's installed when you push from the Setup tab. Importing catalogues and collections from other addons (AIOmetadata, Nuvio.json, etc.) is coming soon.
Collections stay up to date: new films added to a franchise you already own appear automatically (Nuvio fetches the folder's catalog live). One LeLibrary Collections row holds every franchise: in Nuvio it shows as folders, and in Stremio as a genre filter. You can use emojis in any catalogue name.

When you add a brand-new franchise to your library, give it one quick re-push from the Setup tab and its folder will appear in Nuvio.
