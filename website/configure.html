How it works

What LeLibrary does

Reads your TorBox and Real-Debrid downloads, groups episodes into series, fetches TMDB metadata, and serves it all as a Stremio/Nuvio addon.

  • Movies, Series, and Anime — three separate catalogs
  • Supports TorBox + Real-Debrid (merged or separate)
  • Rich stream info: quality, codec, HDR, audio, size
  • Direct playback from the CDN

Privacy

  • API keys are encoded in the addon URL — sent to the server only when Stremio fetches your library
  • Keys are never stored in a database or logged
  • No tracking, analytics, or third-party requests

Requirements

  • A TorBox and/or Real-Debrid account with downloads
  • A free TMDB API key
  • Poster/Ratings/Stream enhancements are all optional
